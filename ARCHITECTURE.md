# Архитектурное руководство my-text-editor

## Принципы архитектуры
1. **Zero JS in QML (Нулевой JS в QML)**:
   - Файлы QML являются строго декларативными: описывают визуальное дерево, привязки свойств (bindings), стилизацию тем и сигналы.
   - Любая процедурная логика, математика, обработка событий мыши/клавиатуры, таймеры и физика вынесены в специализированные модули в папке `js/`.
2. **Single Responsibility и декомпозиция файлов**:
   - Каждый файл выполняет одну конкретную задачу и разделен на компактные независимые модули.
   - Большие монолиты разбиты на модули и фасады с сохранением обратной совместимости.
3. **Изоляция слоев**:
   - `services/` — чистый Python код (работа с диском, окнами, индексом графа и конфигурацией).
   - `js/` — клиентская логика по доменным категориям (`app/`, `editor/`, `graph/`, `tabs/`).
   - `components/` — изолированные декларативные модули интерфейса QML.
   - `views/` — представления верхнего уровня (`window.qml`, `web.qml`).
   - `config/` — каскадные настройки (`default/` и `user/`).
4. **Безопасность данных**:
   - Синхронизация блоков Markdown (`## `) никогда не затирает непустые данные пустой строкой.
   - Коллизии заголовков с разным текстом объединяются (Safe Merge), а не перезаписываются.

## Структура репозитория

```
asleep-pyqt/ (корень проекта)
├── services/                     # Бэкенд на Python (Qt / OS / I/O)
│   ├── block_engine.py           # Парсинг и кэш Markdown-блоков
│   ├── file_service.py           # Файловые операции и нативные диалоги
│   ├── window_manager.py         # Реестр окон ОС и зоны сброса
│   ├── config_service.py         # Парсинг frontmatter, JSONC и каскада настроек
│   ├── graph_service.py          # Построение графа связей и экспорт заметок
│   ├── hotkey_service.py         # Реестр и обработка горячих клавиш (EN/RU раскладки)
│   ├── syntax_highlighter.py     # Подсветка синтаксиса Markdown для QTextDocument
│   └── reloader.py               # Live-reload при разработке
│
├── config/                       # Двухуровневая система конфигурации
│   ├── default/                  # Базовые заводские настройки JSON
│   └── user/                     # Пользовательские переопределения
│
├── js/                           # Клиентская логика JavaScript, разбитая по доменам
│   ├── app/                      # Жизненный цикл приложения
│   │   ├── action_dispatcher.js  # Диспетчеризация действий UI и хоткеев
│   │   └── web_lifecycle.js      # События окна, диалогов и синхронизации
│   │
│   ├── editor/                   # Логика текстового редактора
│   │   ├── editor_keys.js        # Кроссплатформенная обработка клавиш и скан-кодов
│   │   ├── markdown_shortcuts.js # Markdown шорткаты, авто-пары, списки
│   │   ├── block_sync.js         # Анализ и синхронизация блоков ##
│   │   └── mainbar_controller.js # Контроллер листа, плавного скролла и ширины
│   │
│   ├── graph/                    # Логика графа связей
│   │   ├── graph_physics.js      # Симуляция сил (Fruchterman-Reingold / D3-force)
│   │   ├── graph_renderer.js     # Отрисовка на HTML5/QML 2D Canvas
│   │   └── graph_interaction.js  # Зум, панорамирование, перетаскивание, поиск
│   │
│   └── tabs/                     # Логика вкладок и сплитов
│       ├── tab_model.js          # Модель вкладок, CRUD, файлы, открепление
│       ├── tab_split.js          # Разделение экрана на 2 панели (Split View)
│       ├── tab_sync.js           # Синхронизация текста и Markdown-блоков
│       ├── drag_manager.js       # Физика Drag-and-Drop окон и вкладок
│       └── tabs.js               # Фасадный модуль управления вкладками
│
├── components/                   # Декларативные компоненты интерфейса QML
│   ├── editor/                   # Компоненты редактора
│   │   ├── EditorCanvas.qml      # Холст с текстом и номерами строк
│   │   ├── EditorSplitLayout.qml # Сплит-панели редактора
│   │   ├── MainBar.qml           # Область листа документа
│   │   ├── EditorHeader.qml      # Заголовок документа (Sticky Header)
│   │   ├── EditorFooter.qml      # Футер со статистикой слов/знаков
│   │   ├── EditorGutter.qml      # Номера строк
│   │   ├── EditorScrollbar.qml   # Скроллбар
│   │   ├── SheetResizeHandle.qml # Интерактивная граница изменения ширины листа
│   │   └── SyncNotice.qml        # Уведомление о синхронизации блока
│   │
│   ├── graph/                    # Компоненты графа
│   │   └── GraphView.qml         # Декларативный холст интерактивного графа
│   │
│   ├── sidebar/                  # Компоненты бокового меню
│   │   ├── Sidebar.qml           # Боковая панель
│   │   ├── SidebarHeader.qml     # Заголовок сайдбара
│   │   └── SidebarFileList.qml   # Список заметок и файлов
│   │
│   ├── hotkeys/                  # Менеджер горячих клавиш
│   │   └── HotkeyManager.qml     # Централизованная обработка шорткатов
│   │
│   ├── dialogs/                  # Нативные и QML диалоги
│   │   └── EditorDialogs.qml     # Диалоги выбора файлов и папок
│   │
│   ├── window/                   # Оконные компоненты
│   │   └── WindowFrame.qml       # Безрамочный заголовок и изменение размера
│   │
│   └── theme/                    # Динамическая система тем
│       └── Theme.qml             # Цветовая палитра и токены
│
├── views/                        # Представления верхнего уровня
│   ├── web.qml                   # Главный рабочий контейнер
│   └── window.qml                # Корневое ApplicationWindow
│
├── web.py                        # Точка входа приложения (Python Backend + PyQt6)
├── verify.py                     # Скрипт комплексной самодиагностики проекта
└── pyproject.toml                # Зависимости и конфигурация проекта
```

## Диагностика проекта
Перед отправкой изменений запустите:
```bash
uv run python verify.py
```
Скрипт проверяет целостность файловой структуры, импорты сервисов, компиляцию QML и выполнение модульных тестов.
