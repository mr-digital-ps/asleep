# Архитектурное руководство Asleep

## 1. Фундаментальный закон системы: Паттерн Представлений (View Modes)

Каждый из трёх главных горизонтальных поясов блокнота (`Header`, `Sheet`, `Footer`) представляет собой **контейнер с переключаемыми представлениями (Views)**:

```
┌────────────────────────────────────────────────────────────────────────┐
│  HEADER                                                                │
│  ├── Title View     (Основное: имя файла, статус сохранения, бейджи)   │
│  └── Search View    (Поисковое: фильтрация, Command Palette)           │
├────────────────────────────────────────────────────────────────────────┤
│  SHEET (Рабочий лист заметки)                                          │
│  ├── Gutter Area    (Левая адаптивная сервисная зона: точки/строки)    │
│  ├── Content Area:                                                     │
│  │   ├── Source View    (Текстовый режим: чистый текст со скобками {}) │
│  │   ├── Hierarchy View (Блочный режим: карточки без лишнего шума)     │
│  │   └── Graph View     (Графовый режим: связи текущей заметки/проекта)│
│  └── Scrollbar Area (Правая адаптивная зона: трек, ползунок, скраб)    │
├────────────────────────────────────────────────────────────────────────┤
│  FOOTER                                                                │
│  ├── Info View      (Информационное: слова, знаки, уведомления, пин)   │
│  └── History View   (Историческое: таймлайн коммитов, скраббер дат)    │
└────────────────────────────────────────────────────────────────────────┘
```

> [!IMPORTANT]
> **Фундаментальные законы синтаксиса и данных**:
> 1. **Полная очистка**: Убраны все упоминания заголовков `#..######`, тегов и YAML frontmatter (`---`).
> 2. **Закон блоков**: Текст структурирован исключительно в блоки `{ ... }` (или `ИмяБлока { ... }`). Никаких обязательных функций вроде `main`, никаких круглых скобок.
> 3. **Граф связей**: Граф строится **исключительно между файлами** по вики-ссылкам `[[заметка]]`.
> 4. **Макро-навигация**: Перемещение между блокнотами и панелями холста закреплено за комбинацией **`Alt + Стрелки`** (системный `Ctrl` оставлен для микро-навигации по словам и стандартных шорткатов).
> 5. **Адаптивность**: Никаких захардкоженных значений (вроде `36px`) — все отступы, полосы `Gutter` и `Scrollbar` берутся из свойств дизайн-системы `Theme.qml`.
> 6. **Single Source of Truth**: Единый эталонный буфер документа на уровне ядра Python (`DocumentSession` / `QTextDocument`) гарантирует сквозной стек Undo/Redo и точную проекцию курсора между `SourceView` и `HierarchyView`.

## 2. Единый источник правды (Single Source of Truth, Undo/Redo и Курсор)

Чтобы избежать рассинхронизации правок и прыжков курсора при смене режимов:

1. **Единое состояние текста (Master Buffer в Python)**:
   - Текст документа физически хранится в памяти бэкенда (`DocumentSession`).
   - И `SourceView`, и `HierarchyView` работают с проекциями одного и того же мастер-текста.
2. **Сквозной стек Undo/Redo**:
   - Все изменения (ввод в карточке, удаление строки в тексте, перемещение блока через Drag&Drop) фиксируются в едином стеке транзакций бэкенда.
   - `Ctrl+Z` / `Ctrl+Y` в любом режиме откатывает/накатывает изменения глобально для документа.
3. **Бесшовная проекция курсора и скролла**:
   - При переходе `Hierarchy → Source`: позиция активного блока транслируется в смещение открывающей скобки `{` — текстовый курсор и скролл встают ровно на этот блок.
   - При переходе `Source → Hierarchy`: по символьной позиции курсора определяется текущий блок `{ ... }` — список карточек плавно скроллится к нему и активирует фокус.

## 3. Пространственный холст и навигация через Alt

Все глобальные перемещения и переключения режимов строятся вокруг модификатора **`Alt`**:

* **Навигация между блокнотами на холсте**:
  * `Alt + ←` / `Alt + →` — перенос фокуса на соседний блокнот слева / справа.
  * `Alt + ↑` / `Alt + ↓` — перенос фокуса на блокнот сверху / снизу.
* **Переключение представлений листа (Sheet)**:
  * `Alt + 1` — Source View (текст)
  * `Alt + 2` — Hierarchy View (блочные карточки)
  * `Alt + 3` — Graph View (граф связей)
* **Управление поясами**:
  * `Alt + F` — поиск в шапке (Header Search)
  * `Alt + H` — таймлайн истории в футере (Footer History)
  * `Alt + P` — закрепление шапки / футера (Pin)
* **Микро-навигация внутри заметки**:
  * Обычные стрелки `↑ ↓ ← →` (без модификатора) управляют текстовым курсором или выбором активной карточки.

## 4. Полная иерархия структуры проекта (Container-First)

Файловая структура проекта **строго повторяет визуальное дерево приложения**:

```
asleep-pyqt/
│
├── views/                                # Корневые окна ОС
│   ├── window.qml                        # Главное безрамочное окно ApplicationWindow
│   ├── web.qml                           # Корневая сцена рабочей области
│   ├── web_lifecycle.js                  # Жизненный цикл рабочей области и автозагрузка
│   └── action_dispatcher.js              # Центральный диспетчер горячих клавиш к компонентам
│
├── components/                           # Контейнеры интерфейса
│   │
│   ├── canvas/                           # 2D-ХОЛСТ ЗАМЕТОК (Spatial Multi-Pane)
│   │   ├── CanvasView.qml                # Управление сплитами и сеткой блокнотов
│   │   ├── canvas_navigation.js          # Перемещение Alt + Стрелки между панелями
│   │   ├── tabs.js                       # Фасад управления вкладками
│   │   ├── tab_model.js                  # Модель открытых документов
│   │   ├── tab_split.js                  # Управление сплитами холста
│   │   ├── tab_sync.js                   # Синхронизация вкладок
│   │   └── drag_manager.js               # Перетаскивание файлов между окнами/панелями
│   │
│   └── pane/                             # БЛОКНОТ (Панель отдельной заметки)
│       ├── Pane.qml                      # Главный каркас панели (скролл, фон, жесты)
│       ├── pane_controller.js            # Управление зумом, шириной листа и фокусом
│       │
│       ├── header/                       # --- ПОЯС ШАПКИ (Header) ---
│       │   ├── Header.qml                # Контейнер шапки (Sticky Header)
│       │   ├── header_controller.js      # Переключение Title ⟷ Search

│       │   ├── sheet_controller.js       # Управление переключением представлений
│       │   │
│       │   ├── source/                   # Представление 1: Source View (текст)
│       │   │   ├── SourceEditor.qml      # Редактор текста TextArea
│       │   │   ├── bracket/              # Подсветка парных скобок () [] {}
│       │   │   │   └── BracketOverlay.qml
│       │   │   └── shortcuts/            # Обработка Markdown и хоткеев ввода

│       │   │       └── editor_keys.js

│       │   ├── hierarchy/                # Представление 2: Hierarchy View (блоки {})

│       │   │   ├── hierarchy_controller.js# Добавление/удаление/перемещение блоков
│       │   │   └── block/                # Карточка отдельного блока
│       │   │       └── BlockCard.qml     # Карточка блока { ... }
│       │   │
│       │   ├── graph/                    # Представление 3: Graph View (граф связей)
│       │   │   ├── GraphCanvas.qml       # 2D Canvas графа связей

│               │   ├── TimelineTrack.qml # Дорожка снимков с кнопками Play/Step

│
```
