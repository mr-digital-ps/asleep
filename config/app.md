# Руководство по общим настройкам приложения (`app.json`)

Файл настроек: `config/user/app.json` (переопределяет `config/default/app.json`).  
Локальный файл в каталоге заметок: `_app_settings.json`.

---

## Таблица параметров

| Параметр | Тип | По умолчанию | Описание |
| :--- | :---: | :---: | :--- |
| **`auto_save_delay_ms`** | `number` | `1000` | **Задержка автосохранения в миллисекундах** после последней набранной буквы (1000 мс = 1 секунда). Если установлено в `0`, автосохранение отключается, и сохранение происходит только вручную (`Ctrl+S`). |
| **`supported_extensions`**| `list` | `[".md", ".markdown", ".txt"]` | Список расширений файлов, которые отображаются в дереве боковой панели и доступны для редактирования. |
| **`ignored_directories`** | `list` | `[".git", ".venv", "__pycache__", "node_modules"]` | Список скрываемых системных каталогов, которые не сканируются и не загромождают дерево файлов и граф связей. |
| **`language`** | `string` | `"ru"` | Язык интерфейса (`"ru"` или `"en"`). |

---

## Пример настройки

```json
{
  // Более быстрое автосохранение (0.5 секунды)
  "auto_save_delay_ms": 500,

  // Дополнительно открывать файлы заметок .org и .text
  "supported_extensions": [".md", ".markdown", ".txt", ".org", ".text"],

  // Игнорировать временные папки сборщиков
  "ignored_directories": [".git", ".venv", "__pycache__", "node_modules", ".cache", "dist"]
}
```
