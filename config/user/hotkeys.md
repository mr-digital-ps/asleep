# Руководство по горячим клавишам (`hotkeys.json`)

Файл настроек: `config/user/hotkeys.json` (переопределяет `config/default/hotkeys.json`).

Все комбинации клавиш поддерживают работу **в любой раскладке клавиатуры** (как на английской, так и на русской) благодаря отслеживанию сканкодов клавиш.

---

## Синтаксис задания комбинаций

Каждое действие в файле `hotkeys.json` описывается объектом со списком комбинаций в массиве `"keys"`:

```json
"toggle_header_footer": {
  "keys": ["F9", "Ctrl+Shift+H", "Alt+H"],
  "description": "Показать / скрыть заголовок и статус-бар (Header и Footer)"
}
```

### Доступные модификаторы:
- `Ctrl` (в Windows/Linux) / `Cmd` (в macOS)
- `Alt`
- `Shift`
- `Meta` (клавиша Windows / Super)

### Доступные клавиши:
- Буквы: `A` - `Z` (автоматически маппятся на русскую раскладку: `Ctrl+S` срабатывает и на `Ctrl+Ы`, `Ctrl+W` на `Ctrl+Ц` и т.д.)
- Цифры: `0` - `9`
- Функциональные: `F1` - `F12`
- Управляющие: `Return`, `Enter`, `Space`, `Tab`, `Backspace`, `Escape`, `Delete`
- Навигация: `Up`, `Down`, `Left`, `Right`, `Home`, `End`, `PageUp`, `PageDown`
- Спецсимволы: `\\`, `/`, `[`, `]`, `-`, `=`, `,`, `.`, `;`, `'`

---

## Полный список действий (Actions)

| Действие | Назначение | Стандартные клавиши |
| :--- | :--- | :--- |
| **`toggle_header_footer`** | Скрыть / показать верхний заголовок и нижнюю строку состояния | `F9`, `Ctrl+Shift+H`, `Alt+H` |
| **`toggle_footer`** | Скрыть / показать только нижнюю строку состояния | `Ctrl+Shift+F`, `Alt+F` |
| **`toggle_header`** | Скрыть / показать только верхний заголовок документа | `Ctrl+Shift+U`, `Alt+U` |
| **`toggle_sidebar`** | Скрыть / показать боковую панель проводника файлов | `Ctrl+Shift+B`, `Alt+S` |
| **`toggle_split`** | Включить / выключить разделение экрана (Split View) | `Ctrl+\\` |
| **`toggle_centered_mode`** | Переключить лист: по центру $\leftrightarrow$ на всю ширину | `Alt+W`, `Ctrl+Shift+W` |
| **`close_tab`** | Закрыть текущую вкладку / сплит | `Ctrl+W`, `Ctrl+Q`, `Ctrl+F4` |
| **`new_tab`** | Создать новый документ | `Ctrl+N` |
| **`open_file`** | Открыть файл через проводник | `Ctrl+O` |
| **`save_file`** | Принудительно сохранить текущий файл | `Ctrl+S` |
| **`toggle_bold`** | Выделить жирным шрифтом (`**текст**`) | `Ctrl+B` |
| **`toggle_italic`** | Выделить курсивом (`*текст*`) | `Ctrl+I` |
| **`detach_window`** | Открепить документ в отдельное независимое окно | `Ctrl+D`, `Alt+D` |
| **`toggle_graph`** | Открыть интерактивный граф связей заметок | `Ctrl+G`, `Ctrl+Shift+G` |
| **`zoom_font`** | Масштабировать шрифт документа | `Ctrl + Wheel` (колесико мыши) |
| **`duplicate_line`** | Продублировать текущую строку | `Ctrl+D` (в режиме редактора) |
| **`move_line_up`** | Переместить строку вверх | `Alt+Up` |
| **`move_line_down`** | Переместить строку вниз | `Alt+Down` |
| **`toggle_task_checkbox`**| Переключить чекбокс задачи (`- [ ]` $\leftrightarrow$ `- [x]`) | `Ctrl+Enter` |
