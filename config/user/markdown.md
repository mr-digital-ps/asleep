# Руководство по настройке диалекта Markdown (markdown.json)

В **`asleep-pyqt`** правила разбора синтаксиса Markdown (вики-ссылки, теги, блоки трансклюзии, задачи и служебные файлы) вынесены в модульную систему конфигурации.

- **Системные дефолты:** `config/default/markdown.json` (не изменяйте напрямую).
- **Пользовательские переопределения:** `config/user/markdown.json` (все ключи здесь переопределяют дефолтные).

---

## 🛡️ Безопасность и защита от поломки парсера (Safe Regex Fallback)

> [!WARNING]
> Если вы настраиваете собственные регулярные выражения (например, формат тегов или ссылок) и случайно допустите синтаксическую ошибку (незакрытую скобку, некорректный escape-символ `\`), **парсер не упадет и приложение не сломается!**
> 
> Система выполняет безопасную компиляцию: при ошибке в регулярном выражении в лог терминала выводится предупреждение, и парсер автоматически откатывается на безопасный эталонный шаблон из `config/default/markdown.json`.

---

## Доступные секции и параметры

### 1. `wikilinks` (Вики-ссылки и связи между заметками)

Управляет распознаванием внутренних ссылок для построения графа связей и навигации.

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `pattern` | `string (regex)` | `"\\[\\[([^\\]|#]+)(?:#[^\\]|]+)?(?:\\|([^\\]]+))?\\]\\]"` | Регулярка для вики-ссылок `[[Заметка#Секция\|Алиас]]`. Группа 1 — целевой файл. |
| `md_link_pattern` | `string (regex)` | `"\\[([^\\]]+)\\]\\(([^)]+\\.(?:md\|markdown\|txt))\\)"` | Регулярка для стандартных Markdown-ссылок `[текст](файл.md)`. |
| `target_extensions`| `array[string]`| `[".md", ".markdown", ".txt"]` | Расширения файлов, учитываемых при связывании заметок. |
| `case_sensitive` | `boolean` | `false` | Учитывать ли регистр букв при поиске файла-цели по имени (`stem`). |

**Пример кастомизации в `config/user/markdown.json`:**
```jsonc
{
  "wikilinks": {
    // Включаем строгую чувствительность к регистру в именах заметок
    "case_sensitive": true
  }
}
```

### 2. `tags` (Теги)

Определяет, что считается тегом в тексте заметки и как теги объединяются в графе.

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `pattern` | `string (regex)` | `"(?<!\\S)#([a-zA-Zа-яА-ЯёЁ0-9_\\-]+)(?!\\S)"` | Поиск `#тег` (кириллица, латиница, цифры, дефис, подчеркивание). |
| `min_occurrences_for_graph` | `int` | `2` | Минимальное число заметок, в которых должен встретиться тег, чтобы стать узлом в графе. |

**Пример кастомизации:**
```jsonc
{
  "tags": {
    // Показывать в графе только теги, встречающиеся минимум в 3 заметках
    "min_occurrences_for_graph": 3
  }
}
```

---

### 3. `blocks` (Блочный движок и трансклюзия)

Управляет именованными блоками по заголовкам и синхронизацией контента между заметками.

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `heading_pattern` | `string (regex)` | `"^[ \\t]*(#{1,6})\\s+(.+)$"` | Регулярное выражение границы блоков по заголовкам. |
| `smart_enter_auto_fill` | `boolean` | `true` | Автоматически подставлять существующее тело блока при нажатии `Enter` после заголовка. |
| `safe_merge` | `boolean` | `true` | Защита от потери данных: пустой блок никогда не перезапишет блок с текстом. |
| `graph_transclusion_level` | `int` | `1` | Уровень заголовка, при совпадении которого создается общий узел в графе (1 = только `# Заголовок`). |
| `min_occurrences_for_graph`| `int` | `2` | Минимальное число файлов с одинаковым H1 для создания трансклюзионного узла `block:#...`. |

---

### 4. `tasks` (Чек-листы и задачи)

Настройки интерактивных чекбоксов, переключаемых по `Ctrl+Enter`.

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `open_pattern` | `string (regex)` | `"^[ \\t]*[-*+]\\s+\\[ \\]"` | Регулярка для незавершенной задачи. |
| `done_pattern` | `string (regex)` | `"^[ \\t]*[-*+]\\s+\\[[xX]\\]"` | Регулярка для завершенной задачи. |
| `default_marker` | `string` | `"- [ ] "` | Префикс, который вставляется по `Ctrl+Enter` в пустой строке. |

---

### 5. `system_files` (Служебные файлы хранилища)

Файлы, которые исключаются из графа заметок и выполняют мета-функции.

| Параметр | Тип | По умолчанию | Описание |
| :--- | :--- | :--- | :--- |
| `structure_file` | `string` | `"_Структура.md"` | Имя файла виртуального дерева каталога (Outliner). |
| `graph_file` | `string` | `"_Граф связей.md"` | Имя файла автоматической текстовой проекции связей графа. |
| `folder_config_prefix`| `string` | `"_Настройка каталога "` | Префикс файла настроек папки. |
| `ignore_prefixes` | `array[string]`| `["_", "."]` | Префиксы файлов/папок, исключаемых из контентного графа. |

---

## Как применить изменения?

1. Откройте `config/user/markdown.json`.
2. Добавьте нужную секцию с переопределениями.
3. Сохраните файл (`Ctrl+S`).
4. Настройки применятся автоматически на лету без перезапуска приложения!
