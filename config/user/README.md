# Документация конфигурации

В приложении используется гибкая **каскадная трехуровневая система настроек** с мгновенным применением изменений (**Hot Reload**) без перезапуска приложения:

1. **`config/default/<категория>.json`** — системные настройки по умолчанию (поставляются вместе с приложением).
2. **`config/user/<категория>.json`** — персональные настройки пользователя. Все ключи, указанные здесь, переопределяют дефолтные.
3. **`_ <категория>_settings.json`** — локальные настройки конкретной папки заметок (например, `_graph_settings.json` внутри каталога заметок).

> 💡 **Поддержка комментариев**: во всех `.json` файлах конфигурации разрешены комментарии (`// однострочные` и `/* многострочные */`), а также завершающие запятые.

## Категории настроек и руководства

- 🕸️ **[Физика и визуализация графа (graph.md)](./graph.md)** — полное руководство по силам притяжения/отталкивания, эластичности ребер, пластической деформации, размерам узлов и готовым пресетам.
- 📝 **[Настройки редактора текста (editor.md)](./editor.md)** — ширина листа, размер шрифта, межстрочные интервалы, режимы печатной машинки и фокуса.
- ⌨️ **[Горячие клавиши (hotkeys.md)](./hotkeys.md)** — список доступных действий, синтаксис модификаторов и переназначение клавиш.
- 🎨 **[Цветовая тема (theme.md)](./theme.md)** — настройка темной темы, сайдбара, акцентных цветов и границ.
- ⚙️ **[Параметры приложения (app.md)](./app.md)** — задержка автосохранения, форматы файлов и фильтрация папок.
- 📑 **[Диалект Markdown (markdown.md)](./markdown.md)** — регулярные выражения и правила для вики-ссылок, тегов, блоков, задач и служебных файлов.

## Как менять настройки?

1. Откройте нужный файл в папке `config/user/` (например, `config/user/graph.json` или `config/user/editor.json`).
2. Измените интересующий параметр.
3. Сохраните файл (`Ctrl+S`).
4. Приложение **автоматически подхватит новые значения на лету** без перезапуска!
