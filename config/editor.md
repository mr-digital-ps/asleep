# Руководство по настройке редактора (`editor.json`)

Файл настроек: `config/user/editor.json` (переопределяет `config/default/editor.json`).  
Локальный файл в каталоге: frontmatter `_Настройка каталога <имя>.md` или `_editor_settings.json`.

Все изменения вступают в силу **на лету**!

---

## Таблица параметров

| Параметр | Тип | Дефолт | Рекомендуемый диапазон | Описание |
| :--- | :---: | :---: | :---: | :--- |
| **`sheet_width`** | `number` | `800` | `600 — 1400` | **Ширина листа с текстом (px)**. Текст центрируется в окне. Также ширину можно переключать хоткеем `Alt+W` или перетаскиванием левой/правой границы страницы мышью. |
| **`font_family`** | `string` | `"Segoe UI, Inter, ..."` | любой системный шрифт | Семейство шрифтов для текста заметок (например, `"Consolas"`, `"JetBrains Mono"`, `"Fira Code"`, `"Georgia"`). |
| **`font_size`** | `number` | `15` | `12 — 28` | **Размер шрифта текста (px)**. Также масштабируется комбинацией `Ctrl + колесико мыши`. |
| **`line_height`** | `number` | `1.35` | `1.15 — 1.80` | **Межстрочный интервал**. Множитель от высоты шрифта (1.35 = 135%). Обеспечивает комфортную плотность строк при чтении. |
| **`show_line_dots`** | `boolean` | `true` | `true / false` | Отображение маркеров/точек абзацев слева от текста. |
| **`padding_left`** | `number` | `0` | `0 — 50` | Внутренний отступ слева от края листа до текста. |
| **`padding_right`** | `number` | `0` | `0 — 50` | Внутренний отступ справа от текста до края листа. |
| **`padding_top`** | `number` | `6` | `0 — 50` | Отступ сверху листа до первой строки текста. |
| **`padding_bottom`** | `number` | `0` | `0 — 100` | Отступ снизу листа. |
| **`typewriter_mode`**| `boolean` | `false` | `true / false` | **Режим печатной машинки**. Текущая строка ввода всегда автоматически удерживается по центру экрана по вертикали. |
| **`focus_mode`** | `boolean` | `false` | `true / false` | **Режим концентрации (Zen)**. Фокусирует внимание на текущем предложении или абзаце. |
| **`tab_size`** | `number` | `4` | `2 — 8` | Количество пробелов при нажатии клавиши Tab. |

## Примеры настроек

### Пример: «Компактный код / Markdown»
Моноширинный шрифт, мелкий размер, плотные строки:
```json
{
  "sheet_width": 1000,
  "font_family": "Consolas, 'Cascadia Code', monospace",
  "font_size": 14,
  "line_height": 1.25,
  "tab_size": 2
}
```

### Пример: «Книжное чтение»
Шрифт с засечками, комфортная ширина, просторный интервал:
```json
{
  "sheet_width": 720,
  "font_family": "Georgia, 'Times New Roman', serif",
  "font_size": 17,
  "line_height": 1.5,
  "typewriter_mode": true
}
```
