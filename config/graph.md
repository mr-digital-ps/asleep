# Руководство по настройке интерактивного графа (`graph.json`)

Файл настроек: `config/user/graph.json` (переопределяет `config/default/graph.json`).  
Локальный файл в каталоге заметок: `_graph_settings.json`.

Все изменения вступают в силу **мгновенно на лету** при сохранении файла!

---

## 1. Параметры физической модели (`physics`)

Физика графа построена на симуляции взаимодействия частиц (силовая модель Эйлера/Верле) с моделью **пластической упругости связей**.

### Силы взаимодействия

| Параметр | Тип | По умолчанию | Диапазон | Описание и влияние на физику |
| :--- | :---: | :---: | :---: | :--- |
| **`repulsion`** | `float` | `3600` | `500 — 12000` | **Сила взаимного отталкивания узлов** (закон Кулона). Чем больше значение, тем дальше узлы расталкиваются, образуя просторную структуру. Если значение слишком мало, узлы слипаются в кучу. |
| **`repulsionDistanceMax`** | `float` | `800` | `200 — 2000` | **Радиус действия отталкивания (в пикселях)**. Узлы, расстояние между которыми превышает этот порог, не тратят процессорное время на вычисление отталкивания. |
| **`linkDistance`** | `float` | `85` | `30 — 250` | **Равновесная длина связи (ребра)**. Длина пружины, к которой связь стремится вернуться в состоянии покоя. |
| **`linkStrength`** | `float` | `0.014` | `0.002 — 0.2` | **Жесткость связей (закон Гука)**. Малые значения (`0.005 — 0.02`) делают связи мягкими, растяжимыми «как резина». Высокие значения (`0.08 — 0.2`) превращают связи в жесткий каркас. |
| **`gravity`** | `float` | `0.0005` | `0.0001 — 0.005` | **Центральная гравитация**. Постоянная мягкая сила притяжения к центру экрана. Не дает одиночным заметкам или несвязанным островкам улетать за пределы видимости. |

---

### Пластичность и растяжение связей («эффект резины»)

Когда вы захватываете узел мышью и оттягиваете его, ребра растягиваются и могут временно «запоминать» деформацию, а затем плавно возвращаться в форму.

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :---: | :---: | :---: | :--- |
| **`plasticDeformation`** | `float` | `0.035` | `0.0 — 0.1` | **Коэффициент пластической памяти**. При растяжении ребра дальше нормы, его текущая равновесная длина увеличивается с этой скоростью. При значении `0.0` ребро чисто упругое (не запоминает растяжение). |
| **`plasticMaxDistance`** | `float` | `300` | `150 — 800` | **Предел максимального растяжения связи (px)**. Не дает растянуть связь до бесконечности, сдерживая отрыв узлов. |
| **`plasticRecoveryRate`** | `float` | `0.0005` | `0.0001 — 0.01` | **Скорость релаксации**. Темп, с которым растянутое ребро медленно сжимается обратно к базовому `linkDistance`. |

---

### Стабильность и затухание

| Параметр | Тип | По умолчанию | Диапазон | Описание |
| :--- | :---: | :---: | :---: | :--- |
| **`damping`** | `float` | `0.82` | `0.60 — 0.95` | **Коэффициент трения среды**. При `0.70` граф мгновенно замирает без колебаний. При `0.92` узлы долго плавают и пружинят. |
| **`maxVelocity`** | `float` | `15.0` | `5.0 — 40.0` | **Максимальная скорость перемещения узла за кадр (px/frame)**. Препятствует «взрыву» физики при резком перетаскивании узла через экран. |
| **`initialSpread`** | `float` | `0.35` | `0.1 — 1.0` | **Начальный разброс**. Доля от ширины/высоты экрана при первичной случайной расстановке узлов. |

## 2. Параметры внешнего вида (`visual`)

| Параметр | По умолчанию | Описание |
| :--- | :---: | :--- |
| **`nodeRadiusMin`** | `3.5` | Минимальный радиус узла (для заметок с 0–1 связью). |
| **`nodeRadiusMax`** | `8.5` | Максимальный радиус узла (для ключевых заметок-хабов). |
| **`nodeRadiusBase`** | `3.2` | Базовый радиус узла. |
| **`nodeRadiusWeight`** | `1.3` | Добавка к радиусу за каждую входящую/исходящую связь. |
| **`backgroundColor`** | `"#141414"` | Цвет фона холста графа. |
| **`nodeColorFile`** | `"#383838"` | Цвет узлов Markdown файлов (темно-серый). |
| **`nodeColorBlock`** | `"#2a2a2a"` | Цвет узлов блоков трансклюзий (графитовый). |
| **`nodeColorTag`** | `"#323232"` | Цвет узлов хештегов `#тег` (темно-серый). |
| **`nodeHoverBrightness`**| `1.25` | Множитель яркости узла при наведении мыши. |
| **`linkColor`** | `"#242424"` | Цвет линий связей в покое. |
| **`linkHoverColor`** | `"#444444"` | Цвет подсветки связей активного узла. |
| **`labelColor`** | `"#737373"` | Цвет текста названий заметок. |
| **`labelHoverColor`** | `"#ffffff"` | Цвет текста при наведении мыши. |
| **`labelFontSize`** | `10` | Размер шрифта подписей в пикселях. |

## 3. Готовые пресеты физики

Вы можете скопировать любой из этих блоков в свой `config/user/graph.json` в секцию `"physics"`:

### Пресет 1: «Тягучая мягкая резина» (Рекомендуется для экспериментов)
Связи легко тянутся, плавно деформируются и возвращаются назад.
```json
"physics": {
  "repulsion": 3800,
  "repulsionDistanceMax": 900,
  "linkDistance": 80,
  "linkStrength": 0.012,
  "plasticDeformation": 0.045,
  "plasticMaxDistance": 350,
  "plasticRecoveryRate": 0.0006,
  "gravity": 0.0004,
  "damping": 0.84,
  "maxVelocity": 18.0,
  "initialSpread": 0.35
}
```

### Пресет 2: «Плотное кристаллическое ядро»
Компактный, плотно сбитый граф с жесткими связями и быстрым успокоением.
```json
"physics": {
  "repulsion": 1800,
  "repulsionDistanceMax": 500,
  "linkDistance": 45,
  "linkStrength": 0.065,
  "plasticDeformation": 0.01,
  "plasticMaxDistance": 180,
  "plasticRecoveryRate": 0.002,
  "gravity": 0.0009,
  "damping": 0.76,
  "maxVelocity": 12.0,
  "initialSpread": 0.25
}
```

### Пресет 3: «Космическое созвездие» (Просторный и воздушный)
Широко расставленные узлы, парящие в пространстве.
```json
"physics": {
  "repulsion": 6500,
  "repulsionDistanceMax": 1400,
  "linkDistance": 130,
  "linkStrength": 0.008,
  "plasticDeformation": 0.02,
  "plasticMaxDistance": 450,
  "plasticRecoveryRate": 0.0003,
  "gravity": 0.0002,
  "damping": 0.88,
  "maxVelocity": 20.0,
  "initialSpread": 0.50
}
```
