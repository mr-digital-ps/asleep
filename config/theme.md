# Руководство по настройке темы оформления (`theme.json`)

Файл настроек: `config/user/theme.json` (переопределяет `config/default/theme.json`).  
Локальный файл в каталоге заметок: `_theme_settings.json`.

Все цвета применяются **на лету** без перезапуска приложения!

---

## Таблица семантических дизайн-токенов

### 1. Поверхности и фоны (Surfaces)
| Параметр | Тип | Дефолт | Описание |
| :--- | :---: | :---: | :--- |
| **`bg_app`** | `color` | `"#141414"` | Фон подложки всего окна. |
| **`bg_paper`** | `color` | `"#181818"` | Фон листа редактора (sheet). |
| **`bg_sidebar`** | `color` | `"#171717"` | Фон боковой панели (сайдбара). |
| **`bg_header`** | `color` | `"#181818"` | Фон закрепленной верхней шапки. |
| **`bg_footer`** | `color` | `"#181818"` | Фон нижней строки состояния. |
| **`bg_hover`** | `color` | `"#202020"` | Фон кнопок и элементов при наведении мыши. |
| **`bg_active`** | `color` | `"#282828"` | Фон выбранного элемента списка или вкладки. |
| **`bg_dialog`** | `color` | `"#1e1e1e"` | Фон диалоговых и модальных окон. |

### 2. Типографика и текст (Typography)
| Параметр | Тип | Дефолт | Описание |
| :--- | :---: | :---: | :--- |
| **`text_primary`** | `color` | `"#d4d4d4"` | Основной текст заметок и документа. |
| **`text_secondary`** | `color` | `"#737373"` | Вторичный текст (статистика, пути, метаданные). |
| **`text_muted`** | `color` | `"#525252"` | Приглушенный текст (плейсхолдеры). |
| **`text_selected`** | `color` | `"#ffffff"` | Цвет текста внутри выделения. |
| **`text_hover`** | `color` | `"#ffffff"` | Цвет текста при наведении. |

### 3. Редактор текста (Editor Canvas)
| Параметр | Тип | Дефолт | Описание |
| :--- | :---: | :---: | :--- |
| **`cursor_color`** | `color` | `"#e0e0e0"` | Цвет вертикального курсора ввода `"\|"`. |
| **`selection_color`** | `color` | `"#282828"` | Фон выделенного фрагмента текста. |
| **`line_highlight`** | `color` | `"#0effffff"` | Подсветка текущей активной строки. |
| **`gutter_text`** | `color` | `"#505050"` | Цвет маркеров/номеров строк в левой полосе. |
| **`gutter_active`** | `color` | `"#999999"` | Цвет маркера текущей активной строки. |
| **`bracket_match`** | `color` | `"#3b82f6"` | Подсветка парных скобок `()`, `[]`, `{}`. |

### 4. Границы и разделители (Borders)
| Параметр | Тип | Дефолт | Описание |
| :--- | :---: | :---: | :--- |
| **`border_color`** | `color` | `"#262626"` | Тонкие разделительные линии и рамка сплита. |
| **`border_focus`** | `color` | `"#555555"` | Граница поля ввода при фокусе. |
| **`border_hover`** | `color` | `"#333333"` | Границы элементов при наведении. |

### 5. Акценты и контролы (Accents)
| Параметр | Тип | Дефолт | Описание |
| :--- | :---: | :---: | :--- |
| **`accent_color`** | `color` | `"#d4d4d4"` | Главный акцентный цвет (монохромный светло-серый). |
| **`accent_hover`** | `color` | `"#ffffff"` | Акцентный цвет при наведении (чистый белый). |
| **`accent_active`** | `color` | `"#888888"` | Акцентный цвет при нажатии. |
| **`scrollbar_thumb`** | `color` | `"#2c2c2c"` | Цвет ползунка полосы прокрутки. |
| **`scrollbar_hover`** | `color` | `"#3d3d3d"` | Цвет ползунка при наведении. |
| **`danger_color`** | `color` | `"#ef4444"` | Цвет кнопок закрытия и удаления. |
