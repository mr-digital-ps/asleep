# Генеральный План Восстановления Проекта (Execution Roadmap)

> **Цель:** Превратить проект из нестабильного набора абстракций в монолитный, быстрый и неубиваемый текстовый редактор заметок по формуле:
> **Локальный Монолит + Модульная структура по фичам + Запуск нативно через uv + Прямой QObject-мост с сигналами Qt.**

---

## 🎯 Критерий готовности каждого шага (Definition of Done)
1. Команда `uv run .\web.py` запускается мгновенно (до 0.5 сек).
2. В консоли **ноль** ошибок и варнингов.
3. Новая функциональность проверяется руками на экране.
4. Создаётся отдельный чистый git-коммит.

---
