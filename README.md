# asleep-pyqt (v1.0.0)

> **Бруталистская монохромная рабочая станция для сложного нелинейного нарратива, сюжетных графов и схем метрополитена.**

---

## ⚡ О проекте

**asleep-pyqt** — это инструмент для писателей, нарративных дизайнеров и исследователей, работающих с глубокими взаимосвязанными текстами. 

В отличие от раздутых редакторов на Electron (Obsidian, Notion, Logseq), asleep-pyqt спроектирован по принципу **Локального Монолита (Local Monolith)** на базе нативного C++ движка **Qt Quick** и легкого ядра Python.

- 🚀 **Мгновенный запуск**: холодный старт за ~200 мс, потребление ~60 МБ RAM.
- 🎨 **Бесконечный пространственный холст (Spatial Canvas)**: плавное масштабирование, панорамирование средней/правой кнопкой мыши и перемещение карточек с физикой на 120 FPS.
- ✍️ **Сухой монолитный текстовый буфер**: чистое ощущение пишущей машинки, идеальный интерлиньяж (135%), отсутствие прыгающего скролла и визуального мусора.
- 🚇 **Схема метрополитена сюжета (Metro Transit Map)**: автоматическое построение линий персонажей `@[Имя]` и станций `Имя { ... }` с пересадками и таймлайном.
- 🛡️ **Свобода данных (No Vendor Lock-in)**: экспорт в стандартный Markdown (`.md`) в один клик (`Ctrl+Shift+E`).

## 📐 Каноническая система синтаксиса (14 единиц)

| № | Единица синтаксиса | Описание и пример |
|---|---|---|
| **1** | Однострочный именованный блок | `Введение { Краткий тезис }` |
| **2** | Многострочный именованный блок | `Глава { ... текст главы ... }` |
| **3** | Однострочный безымянный блок | Отдельная строка текста вне фигурных скобок |
| **4** | Многострочный безымянный блок | Последовательность абзацев вне фигурных скобок |
| **5** | Локальная трансклюзия | `ИмяБлока()` — живое включение блока из этого же файла |
| **6** | Внешняя трансклюзия | `ИмяФайла.ИмяБлока()` — живое включение фрагмента из другого файла |
| **7** | Вики-ссылки графа | `[[Имя Файла]]` — построение ребер интерактивного графа |
| **8** | Тематические теги | `#тег` |
| **9** | Жирный шрифт | `**жирный текст**` |
| **10** | Курсив | `*курсив*` |
| **11** | Зачёркнутый текст | `~~зачёркнутый текст~~` |
| **12** | Маркированные списки | Маркеры `-`, `*`, `+` |
| **13** | Нумерованные списки | `1.`, `2.`, `3.` |
| **14** | Цитаты | Строки с маркером `> ` |
| **+** | Сюжетные акторы | `@[Имя Персонажа]` — строит линии пересадок в метрополитене |

## ⌨️ Горячие клавиши (Hotkeys)

### Навигация и режимы
* **`Alt+F` / `Alt+C`** — Свернуть / развернуть все блоки документа (Fold All / Unfold All)
* **`Alt+L` / `Alt+E`** — Переключить Live Mode
* **`Alt+S`** — Переключить сухой Source Mode
* **`Alt+M`** — Показать / скрыть схему метрополитена сюжета (Metro Map)
* **`Alt+G`** — Интерактивный граф связей
* **`Alt+H`** — Git Graph таймлайн изменений (сравнение версий)
* **`Alt+D`** — Режим пошагового диффа (Inline Diff)
* **`Alt+U` / `F9`** — Скрыть / показать шапку (Headerless Focus Mode)
* **`Alt+C`** — Режим центрирования листа (Centered Mode)

### Работа с файлами
* **`Ctrl+S`** — Сохранить активную заметку
* **`Ctrl+N`** — Создать новый документ
* **`Ctrl+O`** — Открыть файл
* **`Alt+O`** — Выбрать рабочую папку
* **`Ctrl+W`** — Закрыть активную вкладку
* **`Ctrl+Shift+E` / `Alt+Shift+E`** — Экспорт заметки в стандартный Markdown (`exports/*.md`)

### Управление окном и холстом
* **ПКМ (Drag)** — Плавное перемещение окна приложения по рабочему столу
* **Alt + ЛКМ (Drag)** — Нативное перемещение окна ОС (Aero Snap)
* **СКМ (Drag)** или **Space + ЛКМ (Drag)** — Панорамирование камеры бесконечного холста
* **Alt + Колесо мыши** — Плавный зум холста

## 🚀 Быстрый запуск

### Запуск в один клик (Windows)
Просто дважды кликните по:
- **`asleep.vbs`** — запуск в бесшумном фоновом режиме (без окна черной консоли)
- **`asleep.bat`** — запуск через командную строку

### Запуск через консоль разработчика
```bash
# Установка зависимостей и нативный запуск через uv
uv run .\web.py
```

### Запуск самодиагностики (Healthcheck)
```bash
uv run verify.py
```

## 🏛️ Архитектурные принципы
1. **Config-First**: все настройки, цвета, геометрия и хоткеи объявлены в `config/default/*.json` с безопасным переопределением в `config/user/`.
2. **Безопасность Undo/Redo**: операции сворачивания блоков выполняются через атомарные `QTextCursor` транзакции ядра Qt, сохраняя полную историю `Ctrl+Z`.
3. **Строгое разделение движения**: вкладка двигает вкладку, холст двигает холст. Никаких чужеродных авто-центрирований.
