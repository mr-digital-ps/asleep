# Архитектурный Манифест asleep-pyqt (Iron Rules)

Этот документ определяет архитектурные законы проекта, оптимизированные для максимальной стабильности, простоты сопровождения и минимального расхода контекста/токенов.

---

## 1. Системная архитектура: Локальный Монолит (Single-Process Desktop)
- Все приложение работает строго в **одном процессе Python**.
- Никаких сокетов, RPC-серверов, микросервисов или многопроцессных очередей.
- Запуск строго нативно через `uv run .\web.py` с аппаратной привязкой VSync и `QT_QUICK_CONTROLS_STYLE = "Basic"`.

---

## 2. Архитектура кода: Модульная по фичам (Feature-Based)
Проект организован по изолированным функциональным блокам, а не горизонтальным слоям:
- **`components/editor/`**: всё, что касается листа текста (холст, заголовок, футер, скролл).
- **`components/sidebar/`**: всё, что касается списка заметок и дерева папок.
- **`components/graph/`**: всё, что касается интерактивного графа связей.
- **`components/theme/`**: синглтон темы и токены геометрии/цветов.
- **`config/`**: модульные JSON-конфиги (`theme.json`, `app.json`, `editor.json`, `hotkeys.json`, `graph.json`).

### Принцип изоляции (Черный ящик):
- Компоненты UI **автономны**. Они взаимодействуют с внешним миром только через свои входные `property` и выходные `signal`.
- **Запрещены скрытые глобальные связи:** компонент не должен лезть через `parent.parent.parent` к свойствам чужих панелей.

---

## 3. Здравый баланс логики (Прагматичный QML + JS + Python)
- **QML отвечает за:** структуру, вёрстку, анимации и простое состояние отображения (view state: `visible`, `opacity`, `focus`).
- **Локальные обработчики:** простые действия (`onClicked: root.saveRequested()`) пишутся прямо в QML без раздувания внешних файлов-прокладок.
- **Внешний JS (`*.js`):** используется **исключительно** для сложных чистых алгоритмов без побочных эффектов (физика графа, разметка текста регулярками).
- **Python (`Backend`):** выполняет всю тяжёлую работу с файловой системой, чтением/записью, сканированием хранилища и парсингом ссылок.

---

## 4. Интеграция: Прямой фасад Backend (QObject Bridge)
- В Python бэкенд представлен **единым классом `Backend(QObject)`** в `services/core/` (или `services/backend.py`), экспортируемым в QML как `backend`.
- **Синхронные методы (`@pyqtSlot`)** для мгновенных запросов UI: `read_file()`, `save_file()`, `get_folder_files()`, `get_theme_config()`.
- **Сигналы (`pyqtSignal`)** для реактивных обновлений от системы: `folderFilesChanged`, `themeConfigChanged`, `actionRequested`.

---

## 5. Конфигурация: Config-First Architecture
- **Полный запрет хардкода:** размеры окон, цвета, тайминги, хоткеи, ширина листа и отступы хранятся строго в `config/default/*.json`.
- В QML значения считываются централизованно через `Theme.*` или методы `backend.get_*_config()`.
