1 глава - Сюжет #детектив

Встреча в тумане {
    Вайс передает запечатанный конверт со списком артефактов.
    Элеонора прячет конверт в муфту и оглядывает темный причал.
}

Засада на складе {
        Морган блокирует выходы со склада с револьвером в руке.
        Элеонора отстреливается из-за штабелей ящиков.
}

Тайник в коллекторе {
        Вайс пробирается по пояс в ледяной воде к запасному шлюзу.
        Морган идет по следу фонаря, взводя курок.
}

Допрос в клубе {
        Морган садится напротив графини за дальний угловой столик.
        Элеонора невозмутимо помешивает кофе серебряной ложечкой.
}

Развязка на маяке {
        Вайс держит ящик с артефактами у открытого люка маяка.
        Морган требует положить оружие и ящик на ступени.
        Элеонора перерезает трос подъемника и тушит свет прожектора.
}

Побег на катере {
        Вайс отдает швартовы и запускает дизель катера.
        Элеонора смотрит на отдаляющиеся огни маяка сквозь пелену шторма.
}
