================================================================================
  КАНОНИЧЕСКИЙ СИНТАКСИС ДИАЛЕКТА ASLEEP-FLOW
  Справочное руководство по структуре текста, блокам, графу и схеме метро
================================================================================

Диалект asleep-flow — это строгий, минималистичный текстовый формат для ведения 
заметок, историй и баз знаний в виде чистого плоского текста (.txt / .af). 
Текст остается на 100% читаемым в любом блокноте, но при открытии в редакторе 
asleep-pyqt автоматически трансформируется в интерактивный граф связей, 
хронологическую схему метро и структурированный документ со свёрткой блоков.


--------------------------------------------------------------------------------
1. ЧЕТЫРНАДЦАТЬ ЕДИНИЦ СИНТАКСИСА
--------------------------------------------------------------------------------

1. Однострочный именованный блок:
   Имя { Текст блока на одной строке }
   Пример:
   Испания { Казна истощена после морских экспедиций и конфликтов. }

2. Многострочный именованный блок:
   Имя {
       Первая строка описания.
       Вторая строка описания.
   }
   Пример:
   Османская империя {
       Султан Селим II завершает подготовку эскадры.
       Венеция запрашивает помощь Папского престола.
   }

3. Однострочный безымянный блок:
   Любая отдельная строка текста вне фигурных скобок {}.
   Воспринимается как свободное повествовательное утверждение или мета-комментарий.

4. Многострочный безымянный блок:
   Последовательность строк или абзацев вне фигурных скобок, разделённая пустыми 
   строками. Служит нейтральным вводным или контекстным текстом раздела.

5. Локальная трансклюзия (внутри того же документа):
   Имя()
   Пример:
   Испания()
   В редакторе Live Mode автоматически подтягивает и отображает актуальный 
   блок "Испания" из текущего файла, позволяя переиспользовать фрагмент 
   без дублирования.

6. Внешняя трансклюзия (из другого документа):
   ИмяФайла.ИмяБлока()
   Пример:
   Религиозные войны и Лепанто.Священная лига()
   Подтягивает блок "Священная лига" напрямую из файла "Религиозные войны и Лепанто.txt". 
   В графе связей отображается как пунктирное направленное ребро.

7. Вики-ссылки для графа связей:
   [[Имя Файла]] или [[Имя Файла#Имя Блока]]
   Пример:
   Войска направлены на соединение с [[Династические дуэли и Армада]].
   Создаёт двустороннюю ассоциативную связь в базе знаний и кликабельный переход.

8. Теги:
   #тег
   Пример:
   #дипломатия #флот #кризис #реформация
   В графе связей теги визуализируются как аккуратные сглаженные ромбы, объединяющие 
   разрозненные документы в тематические созвездия.

9. Жирный текст:
   **важный текст**
   Выделяет ключевые термины, даты и имена монархов.

10. Курсив:
    *акцентное слово*
    Используется для терминов на латыни, цитат и смысловых интонаций.

11. Зачёркнутый текст:
    ~~отменённый договор~~
    Используется для расторгнутых соглашений и утраченных статусов.

12. Маркированные списки:
    Маркеры -, * или + в начале строки:
    - Потеря трёх галеонов у мыса Гравелин
    - Отход северным путём вокруг Шотландии
    - Нехватка пресной воды и провианта

13. Нумерованные списки:
    Формат 1., 2., 3.:
    1. Подписание мирного трактата
    2. Признание автономии провинций
    3. Выплата контрибуции

14. Цитаты:
    Строки с маркером > в начале:
    > "Государство — это я, но мир принадлежит коалициям."


--------------------------------------------------------------------------------
2. ВЛОЖЕННОСТЬ И ОБЛАСТИ ВИДИМОСТИ (SCOPES)
--------------------------------------------------------------------------------

Блоки могут свободно вкладываться друг в друга для построения иерархий:

Испания {
    Мадрид {
        Двор Филиппа II принимает посланцев из Рима.
    }
    Нидерланды {
        Герцог Альба вводит Алькабалу — десятипроцентный налог.
    }
}

В редакторе Live Mode:
- В гаттере (на полях слева) появляются направляющие линии скоупа (Scope Guides).
- Напротив имени каждого блока отображается векторный шеврон:
  ▼ — развёрнутый блок (клик схлопывает тело блока в компактное "Заголовок ....").
  ▶ — свёрнутый блок (клик мгновенно разворачивает его обратно).


--------------------------------------------------------------------------------
3. КАК СИНТАКСИС ОТОБРАЖАЕТСЯ В ГРАФЕ (Ctrl+G / Alt+G)
--------------------------------------------------------------------------------

Граф автоматически анализирует синтаксис диалекта:
* Круглые узлы: файлы-документы (заметки и главы).
* Сглаженные пентагоны: именованные блоки внутри файлов.
* Сглаженные ромбы: теги (#тег).
* Сплошные линии: структурные связи и вики-ссылки [[...]].
* Пунктирные линии: трансклюзии блоков Имя() и Файл.Имя().

Горячие клавиши в графе:
* B — включить / выключить слой блоков.
* T — включить / выключить слой тегов.
* L — включить / выключить слой ссылок.
* Shift+B / Shift+T / Shift+L — переключение рёбер (линий) соответствующих слоёв.
* Alt+I — сводная информационная панель графа.


--------------------------------------------------------------------------------
4. КАК СИНТАКСИС ОТОБРАЖАЕТСЯ В СХЕМЕ МЕТРО (Ctrl+M / Alt+M)
--------------------------------------------------------------------------------

Хронологическая схема сюжета транслирует блоки в линии метро:
* Каждый файл — это временной срез / эпоха на горизонтальной шкале.
* Повторяющиеся имена блоков (например, Испания, Франция, Англия, Габсбурги) 
  образуют непрерывные параллельные цветные линии (ветки метро).
* Когда в одном событии или абзаце пересекаются несколько акторов — схема 
  создаёт узловую станцию-пересадку (Interchange Station).
* Клик по станции метро мгновенно открывает соответствующий файл и наводит фокус 
  на нужную строку документа.


--------------------------------------------------------------------------------
5. РЕЖИМЫ РЕДАКТОРА
--------------------------------------------------------------------------------

* Live Mode (Alt+L):
  Фигурные скобки { } аккуратно маскируются под цвет бумаги, в гаттере активны 
  шевроны свёртки ▼/▶ и вертикальные линии скоупов, ссылки кликабельны в один клик.

* Source Mode (Alt+S):
  Сухой монолитный TXT блокнот. Никаких скрытий и оверлеев — вы видите чистый 
  исходный текст в точности так, как он записан на диске. Идеально для быстрой 
  правки и полного контроля над каждым символом.
