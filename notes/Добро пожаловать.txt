Добро пожаловать в asleep-pyqt — рабочую станцию для нелинейных текстов.

Начало {
    Этот документ демонстрирует каноническую систему диалекта.
    Здесь вы можете свободно писать мысли, дробить их на блоки и строить связи.
    @[Автор] запускает систему.
}

Возможности {
    - **Сворачивание всех блоков**: нажмите `Alt+F` (или `Alt+C`), чтобы свернуть текст в оглавление.
    - **Live Mode / Source Mode**: переключайтесь между режимами через `Alt+L` и `Alt+S`.
    - **Схема метро**: нажмите `Alt+M`, чтобы увидеть ветки персонажей и станции.
    - **Интерактивный граф**: нажмите `Alt+G`, чтобы открыть карту связей [[Новая заметка]].
    - **Экспорт в Markdown**: нажмите `Ctrl+Shift+E`, чтобы выгрузить чистый `.md`.
}
