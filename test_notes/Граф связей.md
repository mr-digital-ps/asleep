# Граф связей

Интерактивный Force-Directed граф заметок в стиле Obsidian.

## Особенности
- Построен для [[Фронтенд]]
- Запланирован в [[Спринт 2]]
- Связан с разделом [[Идеи и фичи]]

# Общие заметки
Единая база заметок синхронизируется между всеми ключевыми документами проекта. Любые изменения здесь автоматически отражаются в связанных модулях.
