# Запрещенные практики и неудачные решения (Табу)

Этот документ фиксирует идеи, архитектурные решения и фичи, которые были опробованы, признаны нежизнеспособными или прямо запрещены в проекте `asleep-pyqt`. **Не пытаться повторять или реализовывать их снова.**

---

### 1. Табу: Overscroll и искусственный Footer в редакторе
- **Попытка:** Реализовать свободную прокрутку редактора ниже последней строки текста (overscroll / bottom margin / padding) и зафиксировать нижний футер.
- **Почему не получилось / запрещено:**
  - `QQuickTextEdit` / `TextArea` в Qt Quick нестабильно ведут себя при динамических отрицательных смещениях и искусственных отступах, ломается расчет позиции курсора и мышиных кликов.
  - Нарушает ощущение нативного компактного блокнота.
- **Правило:** Контент и скролл должны быть строго естественными по высоте текста (`contentHeight`). Просить сделать overscroll и искусственный футер — бесполезно.

---

### 2. Табу: Вложенные тяжелые `TextArea` для каждого отдельного абзаца
- **Попытка:** Делать Live Mode как дерево из десятков вложенных `TextArea` на каждую строку/параграф.
- **Почему не получилось / запрещено:**
  - Каждый экземпляр `TextArea` в Qt создает тяжелый `QQuickTextDocument`, контекст ввода ОС и перегружает рендерер при листании больших файлов.
- **Правило:** Live Mode сегментируется крупными логическими блоками (`LiveBlockItem`, `LiveTextItem`), а для чистого текста используется легкий `Text` с переключением на `TextArea` только при прямом фокусе/клике.

---

### 3. Табу: Синие/цветные веб-дефолты для ссылок и тегов
- **Попытка:** Оставлять стандартный HTML `<a>` без явного переопределения палитры в RichText.
- **Почему запрещено:**
  - Движок RichText в Qt по умолчанию подставляет синий цвет `#0000ff` для `<a>`, что разрушает строгую темную монохромную эстетику редактора.
- **Правило:** Все интерактивные элементы и подсветка должны строго соответствовать дизайн-системе `Theme.*` (монохромный акцент `#d4d4d4`, вторичный текст `#737373`).
